# Project Map

## Purpose
Automated measurement of web landing pages to catch problems that make Google Ads reject ads as "Destination not working" (anti-bot browser-check interstitials, redirects, error codes, slow first loads). Current case: middex.cz behind FORPSI hosting protection (tasks/001-forpsi-browser-check.md).

## Requirements
- Measure every URL in sites.yml, or ad-hoc URLs via --url.
- Simulate a crawler without JS/cookies (several UAs) and real browsers (cold + warm visits).
- Produce a FAIL / WARN / OK verdict per URL with reasons.
- Keep a history of results and a static HTML report.
- (New, 2026-10-21) Public web dashboard for owner, PPC agency and client; trends over time (count of 200 vs 4xx/5xx pages across sites.yml, average latency, per-page latency); simplest possible architecture; auth planned later.
- (Next phase, not started) SEO and AIO suggestions generated from web analysis.

## Components (implemented, verified in code)
- webanalyst/__main__.py: CLI (argparse), loads sites.yml, runs probes per URL, `verdict()` rules, `_save_shots()` moves base64 screenshots into docs/shots, writes results JSON, calls report.build.
- webanalyst/http_probe.py: plain HTTP probe per user agent (`USER_AGENTS`, `probe`, `probe_all`), uses requests.
- webanalyst/browser_probe.py: Playwright probe (`probe`, `_visit`, `_screenshot`), Firefox and Chromium, cold/warm visits.
- webanalyst/detect.py: HTML analysis (`analyse_html`, `title_of`) that detects browser-check pages.
- webanalyst/report.py: builds docs/index.html from results/ (HTTP table, browser table, history).
- webanalyst/summary.py: verdict table for the GitHub job summary.
- tests/test_detect.py: tests for detect.py.

## Main Flow
```
sites.yml / --url
   │
   ▼
__main__.main ──per URL──▶ measure_url
                             ├─▶ http_probe.probe_all ──uses──▶ detect.analyse_html
                             ├─▶ browser_probe.probe (firefox, chromium+AdsBot UA) ──▶ detect? (not verified)
                             │       └─ screenshots ─▶ _save_shots ─▶ docs/shots/
                             └─▶ verdict() ─▶ FAIL/WARN/OK + reasons
   │
   ▼
results/<site>/<stamp>.json + latest.json ──▶ report.build ──▶ docs/index.html
```
